# Projet Exercice

## Role

Ce dossier contient une base minimale pour faire vos propres exercices en C sur la manipulation de fichiers.

## Etat actuel

Le fichier `main.c` contient uniquement un programme de test :

```c
printf("Hello world!\n");
```

## Fichiers du dossier

- `main.c` : point de depart a completer.
- `exercice.cbp` : projet Code::Blocks.
- `Série d'exercices_Fichiers (partie 1).pdf` : sujet ou support d'exercices.

## Suggestions d'utilisation

Vous pouvez reutiliser ce dossier pour :

- creer un exercice de lecture de fichier texte ;
- ecrire un programme de sauvegarde binaire d'une structure ;
- tester `fopen`, `fclose`, `fprintf`, `fscanf`, `fwrite` et `fread`.

## Compilation

```powershell
gcc .\main.c -o .\exercice.exe
.\exercice.exe
```
